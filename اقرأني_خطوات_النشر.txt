جدار التسامح — نسخة المشاركة المباشرة مع التحكم بالإغلاق

1) أنشئي مشروعًا في Supabase.com.
2) افتحي SQL Editor ونفذي محتوى supabase_setup.sql.
3) من Authentication > Users أنشئي حسابًا للمعلمة بالبريد وكلمة المرور (أو سجليه بطريقة مفعلة).
4) انسخي User UID الخاص بالحساب، وشغلي في SQL Editor:
   insert into public.wall_admins(user_id) values ('USER_UID_HERE');
5) من Project Settings > API انسخي Project URL والمفتاح العام anon/publishable فقط، ولا تنسخي service_role أو secret key أبدًا.
6) افتحي index.html بمحرر نصوص واستبدلي PASTE_SUPABASE_PROJECT_URL و PASTE_SUPABASE_ANON_KEY بالقيم الصحيحة.
7) ارفعي index.html وgarden.png إلى GitHub Pages. لا يلزم رفع ملف SQL أو هذا الشرح إلى موقع الطالبات.
8) افتحي رابط GitHub، ثم لوحة المعلمة، وسجلي الدخول. حددي نهاية الوقت ثم افتحي المشاركات.
9) جرّبي من هاتف آخر: تظهر الرسائل للجميع بعد التحديث خلال 8 ثوانٍ. بعد نهاية الوقت يتوقف الإرسال من جهة قاعدة البيانات نفسها، حتى لو بقيت صفحة الطالبة مفتوحة.
10) شاركي الرابط نفسه مع الإدارة؛ يبقى للعرض بعد الإغلاق.

مهم: لا يمكن لصفحة GitHub Pages وحدها حفظ رسائل جماعية. قاعدة Supabase مطلوبة لهذا التصميم، لكن Google Sheets غير مطلوب.
النشر المباشر يسمح بظهور الرسائل غير الملائمة فورًا قبل حذفها؛ راقبي المشاركات. استخدمي أسماء اختيارية ولا تطلبي بيانات شخصية حساسة.
لإلغاء وقت البداية أو النهاية اتركي الحقل فارغًا ثم احفظي.
إذا لم تري الرسائل، افحصي عنوان المشروع والمفتاح العام وسياسات قاعدة البيانات.
